# Volei Score

Static React + TypeScript + Vite PWA volleyball scoreboard.

## Scripts

- `npm run dev` - local dev
- `npm run test` - unit tests
- `npm run lint` - eslint
- `npm run build` - production build

## Stack

- React 19
- TypeScript (strict)
- Tailwind CSS
- vite-plugin-pwa
- Vitest + Testing Library
